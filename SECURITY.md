# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability reporting for
this repository, or email maurya373@gmail.com with a short description, reproduction steps, and any potential impact.
You should receive an acknowledgement within seven days.

## Scope

Mouthpiece is designed as a single-user, loopback-only service. Reports involving token handling, local file
permissions, installer behavior, hook integrations, or provider credentials are especially welcome.

## Supported versions

Security fixes are applied to the current `main` branch. There are not yet versioned releases.
